# hmpps-probation-frontend-components

`hmpps-probation-frontend-components` is a Node.js client library to simplify the process of incorporating global components
within PDS applications. We welcome feedback on the [#moj-design-system-support Slack channel](https://moj.enterprise.slack.com/archives/CH5RUSB27) in order to improve it.
